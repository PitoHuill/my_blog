## 为什么选择静态博客

一个好的个人博客不需要复杂的功能。它应该先让你愿意写，然后让读者愿意停留。

Astro 在构建时生成 HTML，不需要数据库或长期运行的服务器，因此很适合部署到 GitHub Pages。内容和页面代码仍然保存在同一个仓库中，也更容易备份和迁移。

## 结构比功能更重要

我把内容、页面和视觉系统分开：文章只负责表达，组件负责呈现，主题变量负责维持整体秩序。

```ts
const principle = {
  content: '表达',
  components: '呈现',
  theme: '秩序',
};
```

当每一部分都有清楚的边界，博客便会随着内容积累而自然生长。

## 给未来留下空间

第一版只解决阅读、写作和发布。评论、统计和更多内容模块可以之后再加，但文章链接和内容结构应该从一开始就保持稳定。
